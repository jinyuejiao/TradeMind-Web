10. 软件的主要功能（500~1300字）
商贸智脑（TradeMind）是一套面向中小微企业的智能化综合经营管理平台，采用前后端分离与微服务架构，通过 API 网关统一对外提供服务，支持多租户 SaaS 模式与多行业版本适配。

（一）租户与身份认证
系统提供租户注册、登录、短信验证与用户管理功能。注册时可选择商户类型（批发、电商、外贸、工贸），开通试用订阅并绑定推荐码。登录后签发 JWT 令牌，内含租户 ID、用户角色、商户类型、订阅档位及访问模式等信息。网关对令牌验签并向下游服务透传身份上下文，实现全链路租户隔离与权限控制。

（二）多行业版本与身份感知界面
平台支持批发（WHOLESALE）、电商（ECOM）、外贸（FOREIGN_TRADE）、工贸一体（FACTORY_TRADE）四种业态。前端根据 JWT 中的商户类型动态加载对应行业 UI 片段与业务模块，实现身份感知渲染（IAR），同一套系统可适配不同经营场景，降低多业态扩展成本。

（三）AI 智能录单
集成阿里百炼（DashScope）大模型，支持语音、图片、文本多模态订单智能提取。用户在工作台发起录单后，系统将媒体上传至对象存储，调用 AI 服务执行语音识别或视觉理解，再由大语言模型按结构化 Schema 输出客户信息、订单明细及新产品建议。提取结果写入 AI 操作记录，经人工审核确认后正式落库并驱动库存变更，显著提升录单效率、减少人工录入错误。

（四）产品与库存管理
提供产品档案维护、SKU 管理、单位换算、多级批发价及低库存预警。支持多仓库管理与分仓库存维护，实现仓库间调拨及批量库存调整。订单确认与发货环节按物流状态精准扣减库存，并通过幂等标志防止重复出库，保障库存数据准确。

（五）销售与进货单据管理
销售订单支持物流状态与财务状态双线模型：物流侧涵盖待配货、拣货、发货、签收、退货等流程；财务侧支持未收款、部分收款、已结清、坏账等状态，并可独立登记收款流水。进货单同样区分物流与财务状态，支持草稿、审核、分批入库、作废等完整供应链流程，并与仓储库存联动。

（六）客户关系与生产管理
CRM 模块提供客户档案、跟进记录与时间轴展示，外贸版支持多币种结算与国际节日交期预警。工贸版扩展 BOM 物料清单与 SOP 生产排产，管理生产进度、风险等级与交期预警，支撑产销协同。

（七）订阅计费与推广体系
系统内置订阅方案管理，按业态与等级配置用户、产品、客户、供应商等配额上限。支持试用开通、付费续费、升级补差及杭州银行收银台支付回调。订阅过期后网关按访问模式（FULL / READ_ONLY / BILLING_ONLY）限制写操作。同时提供推荐码、推广员门户与奖励结算能力，支撑平台商业化运营。

（八）运维中台与移动端适配
运维中心面向平台管理员，提供租户资源快照、AI Token 用量统计、订阅权益审计、系统公告及推广员管理等功能。前端采用响应式布局，在移动端自动切换单栏界面与触控优化交互，满足外出录单、查库存等移动办公需求。

11. 软件的技术特点（0~100字）
采用 Spring Cloud 微服务与 JWT 网关鉴权；多租户 SaaS 与四业态身份感知渲染；阿里百炼多模态 AI 智能录单；订单物流与财务双线驱动库存精准出入库。
